Honeywell Eclipse Spark Ignition Electrode 10019728

Product Code: 10019728 / 019728
Part Number10019728 / 019728
Product TypeBurner Spark Electrode / Ignition Rod (Self-Grounding)
Electrode Base Depth70 mm
Thread Type / SizeM14 (14mm x 1.25mm)
Electrode Gap Distance1.5 mm
Hex Nut Dimension13/16 in.
Terminal InterfaceRemovable terminal, 8-32 NC thread
Operating Temperature-100°C to 1350°C
Burner CompatibilityEclipse AH air-heating burners and similar specialized industrial equipment
ManufacturerHoneywell Eclipse

The Honeywell Eclipse 10019728 (also marked 019728) is a self-grounding burner spark ignition electrode with a 70mm base depth and M14 x 1.25mm threaded mounting. It features a 1.5mm fixed spark gap, a 13/16 in. hex nut for installation, and a removable 8-32 NC terminal for ignition cable connection. Rated for continuous operation from -100 degC to 1350 degC, it is used on Eclipse AH air-heating burners and similar specialized industrial combustion equipment. Manufactured by Honeywell Eclipse.
